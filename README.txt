PAYMENT
This prototype uses a MANUAL payment flow:
- Player sees the MTN MoMo contact.
- Player sends GHS 5.
- Owner verifies the payment manually.
- Owner provides an unlock code.
- Demo unlock code in this prototype: BASIT5

IMPORTANT
The demo unlock code is NOT secure for a real commercial launch. Do not use it as the real payment verification system.
For a real launch, move payment verification to a server/backend and connect an approved MTN MoMo Collections integration. Never put MTN API secrets in game.js or other public frontend files.

MTN says its Collections product supports collecting payments from customers, and its Ghana documentation describes a collections account and transaction reporting. Live API use requires the appropriate onboarding/registration. See the official MTN MoMo developer portal.
